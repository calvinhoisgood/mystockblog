為什麼 Base 不是 20x？

收入與 EPS 上修速度、75% 毛利率、AI 平台地位與產品迭代速度均遠高於普通成熟半導體公司。FY2028 EPS 共識 90 日內由約 $12.7 上修至 $15.7，盈利修正是正向而非惡化。

為什麼 Base 不是 30x？

10 年期美債收益率約 5.3%，提高股東要求報酬率；同時供應承諾、資料中心擔保、延長客戶付款期等使資本風險上升。因此 30x 應留給「現金流同步改善 + 資本風險可控」的 premium 狀態。

Base 對帳：FY2028 正常化 EPS $15.6 × 25x = $390 遠期條件價值 → 以 10% 要求報酬率折回約 $344 → 加約 $3/股折價後非核心投資價值 = 約 $347。
Forward P/E 與 Future Exit P/E 分開：目前 FY28 P/E ≠ FY28 當時的合理倍數折現率與倍數不重複完整計入同一利率風險

為甚麼不是直接拿 Headline FCF？

Economic FCF（經濟自由現金流）要回答的是：維持現有收入能力後，普通股股東真正可拿走多少現金。對 NVIDIA，需特別檢查應收帳款、存貨、供應預付款、AI 基建承諾與 SBC 的經濟效果。

No-Growth Counterfactual｜零成長反事實：如果 NVIDIA 不追求新增市場份額，只維持現有 AI 平台競爭力，仍需要多少研發、運算基建、供應鎖定與生態投資？這些不能因公司稱為「growth investment」就全部從 owner earnings 消失。

SB Energy / OpenAI 擔保

NVIDIA 為 Ohio PORTS-Pike 約 4.25GW IT 負載的土地、電力與殼體建設提供信用支持，總支付義務上限 $105B，按資料中心投入服務分階段生效；首批預計由 FY2029 起。觸發條件包括 OpenAI 破產或租約付款違約。

這不是今天直接從市值扣 $105B，而是 path-dependent claim｜路徑依賴請求權：只有特定條件觸發，損失才會實現。

為甚麼這會改變合理 P/E？

以前 NVIDIA 主要把資本密集部分留給晶圓代工、雲端與資料中心夥伴；現在為了鎖定 AI 工廠需求，公司更主動承擔供應、融資與信用風險。這可能擴大收入與增長持續期，但也令資產負債表的尾端風險上升。

因此我把這項風險的 Primary Risk Location（主要風險位置） 放在 Tail / Claims / Financing scenario，而不是同時大幅提高折現率、壓低 Base P/E、再做一次 Bear haircut。

市場隱含條件

若 FY2028 當時 NVIDIA 仍值得 25x，今天 $233.95 實際只要求 FY2028 EPS 約 $10.5，顯著低於目前共識約 $15.7。

若未來只值 20x，則現價要求 EPS 約 $13.1；仍低於 Base。

因此，要證明目前股價「並不便宜」，需要其中至少一項成立：盈利大幅低於共識、合理倍數永久壓到約 15x，或 資本/擔保損失出現 EPS 共識尚未捕捉的股東價值侵蝕。

Reverse DCF / Reverse P/E 的用途不是再製造一個目標價，而是回答：市場已經在押注哪些成功與失敗條件？目前市場對 NVDA 的定價，已經包含相當程度的增長降速與倍數壓縮。
Reverse Valuation 已完成避免用現價反推一個「看起來合理」的 Base 倍數

Double-Count Audit｜重複計價審計

✓ 投資收益從核心 EPS 剔除，非核心投資只有限度 NAV 加回。

✓ Equity P/E 使用 after-interest EPS，因此不再機械扣同一債務本金。

✓ SBC 已進 FY2027 Non-GAAP，因此不在 EPS、稀釋、FCF、multiple 全額重複扣減。

✓ 高利率主要放在 Required Return，而不是同時完整壓縮 Base P/E。

✓ SB Energy/OpenAI 擔保放在 Tail / Claims；Base 不直接扣最大名義敞口。

方法獨立性：FY2028 P/E 與 FY2028 PV 本質共享同一 EPS / multiple，只是做時間折現，不能算第二個獨立估值方法；反向估值主要是市場預期測試。
